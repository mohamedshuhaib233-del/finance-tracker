# finance-tracker

A private, offline-first personal finance management application with PIN lock security, multi-account tracking, AI Money Coach, and voice-assisted expense recording.

## Features
- **Offline-First Storage**: IndexedDB (Dexie.js) database runs completely locally in the browser.
- **Lock & Security System**: 4-digit PIN protection, auto-lock on tab switch/resume, and simulated biometric unlock.
- **Multi-Account Management**: Track Bank, Cash, Credit Card, and UPI wallets with strict accounting principles.
- **Budgeting & Savings Goals**: Monthly allowances, custom event budgets, and dynamic target savings calculations.
- **AI Money Coach**: Income allocation planning, financial health diagnosis across 9 indicators, and predictive forecasts.
- **Voice Entry**: Voice-to-text transaction recording with NLP entity extraction and confirmation preview.

## Getting Started
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
